# Stam-OCR scoring engine — Apple Silicon native (no Docker, no Rosetta).

# Mirrors Stam-OCR/requirements.txt with three deliberate changes:
#
#   tensorflow-cpu  -> tensorflow-macos   arm64 wheels. Still TF 2.15, so
#     ==2.15.1           ==2.15.0         tensorflow.keras is the embedded
#                                         Keras 2 that loads the legacy .h5
#                                         classifier. Do NOT jump to TF 2.16+,
#                                         where tensorflow.keras is Keras 3 and
#                                         the .h5 load path changes.
#
#     Note the patch version. tensorflow-macos 2.15.1, 2.16.1 and 2.16.2 are
#     published as EMPTY redirector wheels — a few kilobytes of metadata that
#     declare a dependency on themselves, so pip reports success and installs no
#     `tensorflow` module at all. 2.15.0 is the last real build (209 MB). If
#     `import tensorflow` fails on a venv that pip said was fine, this is why.
#   torch==2.3.0+cpu -> torch==2.3.0      the +cpu local build is Linux-only;
#                                         on macOS the plain wheel is CPU anyway.
#   dropped         utils, statistics,    not imported by the scoring path.
#                   pytesseract,          `statistics` in particular is a py2-era
#                   Werkzeug, matplotlib, PyPI package that shadows the stdlib
#                   contourpy             module and breaks the interpreter.
#
# Requires Python 3.11 — TF 2.15 publishes no cp312+ wheels.
